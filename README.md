### 🧩 BMB ECommerce — API + Storefront in One ASP.NET Core App

📌 JWT-secured e-commerce API and its storefront in a single app: strict 3-layer architecture, audit trail and soft delete on every entity, and a guarded order state machine

🔹 **API → BLL → DAL** with one-directional dependencies, Generic **Repository + Unit of Work**
🔹 ASP.NET Core Identity + JWT Bearer (Admin / Customer role claims) across **26 endpoints**
🔹 Order-spam guard: three same-day cancellations arm a 6-hour checkout ban → **HTTP 429 + `Retry-After`**
🔹 Soft delete & full audit trail on every entity via EF Core global query filters
🔹 Transactional checkout with per-line price snapshots, stock accounting & cancellation restock
🔹 Dependency-free **vanilla JS storefront** served from `wwwroot` — no framework, no build step
🔹 **57 xUnit integration tests** driving the real HTTP pipeline against in-memory SQLite

🧰 ASP.NET Core 6 · C# 10 · EF Core 6 · SQL Server · JWT · Swagger · xUnit · Vanilla JS

💻 Repository:
https://github.com/Andrew702/BMB-ECommerce
